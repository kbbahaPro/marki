# Design system

The interface follows three ideas: **calm neutral ground**, **one action colour plus one "marker" for the chosen thing**, and **shapes taken from the product itself**.

## Brand: Marki

The mark is a **bookmark** (the time slot you keep) holding a **3×3 dot grid** (the calendar), with **one dot marked** in orange (the time that was picked): *mark that time*. The wordmark is lowercase **marki** in Outfit Bold with tight tracking.

| Asset | Where |
|-------|-------|
| `<x-brand-mark />` | Inline SVG; colours follow the brand tokens, so it changes with `BRAND_PRIMARY` / `BRAND_MARKER` and dark mode |
| `<x-application-logo />` | Mark + wordmark (or `BRAND_LOGO_URL` if set) |
| `public/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `brand/mark-*.png` | Generated by `php resources/brand/build-icons.php`; PNGs are used in emails, where SVG is blocked |

All of it is configurable; see the Branding section of the README.

## Shapes

**The time slot is a pill.** A booking is a time slot, and a time slot is drawn as a pill:

| Size | Where |
|------|-------|
| Text size | badges (`.pill-*`), time ranges in lists, the duration chip on event types |
| Control size | every button (`.btn-*`), bookable times (`.slot`), tabs (`.tabs`), the active nav item |
| Card size | the "marked" tick on the confirmation page |
| Background | faint, cropped pills (`.motif`) behind the public pages, the confirmation header and the "Next up" card |

**The brand mark** appears once at very large scale, cropped by the viewport, on the sign-in page.

Do not introduce other decorative shapes (blobs, hexagons, gradients). Inputs and cards use a modest `rounded-xl` / `rounded-2xl` so the pill stays special.

## Colour

All colours are semantic tokens defined once in `resources/css/app.css` (light and dark values) and exposed as Tailwind utilities in `tailwind.config.js`. Views never use raw palette classes such as `text-gray-500`.

| Token | Use |
|-------|-----|
| `canvas`, `surface`, `surface-2`, `line` | page background, cards, subtle fills, borders |
| `ink`, `ink-2`, `ink-3` | primary, secondary and tertiary text (all ≥ 4.5:1 on their backgrounds) |
| `primary` (+ `hover`, `ink`, `soft`) | actions, links, focus rings, available dates |
| `marker` (+ `ink`) | **only** the chosen thing: the selected date, "your time", the next meeting, the confirmation tick. Always with dark `marker-ink` text (`.marked`) |
| `success`, `warning`, `danger` (+ `soft`) | meaning only: confirmed, needs attention, error |

`primary` and `marker` come from `BRAND_PRIMARY` / `BRAND_MARKER` at runtime. `App\Support\BrandPalette` derives the hover, link and tint shades for both themes and darkens or lightens them until text contrast meets WCAG AA (tests cover pale, saturated and near-black inputs). The values in `app.css` are the Marki defaults and the fallback.

Dark mode follows the operating system (`prefers-color-scheme`) by switching the token values; no `dark:` classes are needed in views.

## Type

| Face | Use |
|------|-----|
| **Plus Jakarta Sans** (variable) | everything by default |
| **Outfit** (variable), `font-display` | the wordmark, page titles and the sign-in tagline |

Both are bundled through `@fontsource-variable/*`, so no request goes to a font CDN. Use `tabular-nums` wherever times are listed.

## Components

Shared classes live in `@layer components` in `resources/css/app.css`: `.card`, `.btn-primary`, `.btn-secondary`, `.btn-danger`, `.btn-ghost`, `.input`, `.label`, `.checkbox`, `.pill-*`, `.slot`, `.marked`, `.alert-*`, `.tabs`/`.tab`, `.page-title`, `.section-title`, `.wordmark`, `.muted`, `.link`.

Icons are inline Lucide SVGs via `<x-icon name="…" />` (`resources/views/components/icon.blade.php`); no emoji as icons. People are shown with `<x-avatar>` (photo, or initials on the primary colour).

## Accessibility checklist

- Visible focus ring on everything focusable (`:focus-visible` in `app.css`).
- Touch targets at least 44 px (`.btn`, `.slot`, calendar days).
- Motion is limited to 150 ms colour/opacity transitions and is disabled under `prefers-reduced-motion`.
- Status changes use `role="status"` / `role="alert"`; icon-only buttons carry `aria-label`.
- Never put text on the marker colour except `marker-ink`, and never use the marker for actions; it means "chosen", not "click".

## Previewing

With `APP_ENV=local`, `/_preview/page/login` and `/_preview/page/forgot-password` show signed-out screens while you are signed in, and `/_preview/mail/{guest|host|meeting-link|ics}` render the booking emails.
